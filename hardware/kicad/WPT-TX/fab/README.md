# 発注用データの出力

`fab/export.sh` を実行すると、`fab/out/` に製造・実装用のデータ一式が出力される（KiCad 10 の `kicad-cli` が必要、`fab/out/` は git 管理外）。

```sh
sh hardware/kicad/WPT-TX/fab/export.sh
```

## 出力内容

| フォルダ | 内容 |
|---|---|
| `out/gerber/` | 4 層分の銅箔（F / In1 / In2 / B）、レジスト、ペースト、シルク、外形のガーバーと、Excellon ドリル（PTH / NPTH 別ファイル）、ドリルマップ |
| `out/assembly/HRTIM/` | HRTIM 構成（**今回発注する構成**）。`bom_HRTIM_pcbway.csv` が発注用 BOM（型番単位で 1 行、PCBWay の列構成、SMD / THT の別、実装指示つき）。`placement_HRTIM.csv` は全部品の座標、`placement_HRTIM_smd.csv` は表面実装部品のみ。`bom_HRTIM.csv`・`parts_HRTIM.csv` は KiCad の書き出しそのまま（参考） |
| `out/assembly/Legacy/` | Legacy 構成の同じファイル一式 |
| `out/doc/` | 構成ごとの回路図 PDF（`schematic_HRTIM.pdf`）と表面・裏面の実装図（`assembly_front_HRTIM.pdf`、`assembly_back_HRTIM.pdf`。実装しない部品は × 印）。**発注には HRTIM の付いたファイルだけを渡す** |

- 発注用 BOM（`bom_<構成>_pcbway.csv`、`fab/bom_pcbway.py` が作る）は**メーカー型番だけ**で 1 行にまとめる。列は Item # / Designator / Qty / Manufacturer / Mfg Part # / Description / Value / Package/Footprint / Type（SMD・THT）/ Your Instructions / Notes。DNP の部品とテストポイント（部品ではない）は含めない。HRTIM 構成で 74 行（うち 1 行は基板データに無いジャンパ 2 個、`fab/bom_extra.csv`）、基板上の部品は 194 点（表面実装 177、スルーホール 17）。型番の無い行は無い。
- KiCad の書き出しそのままの `bom_<構成>.csv` は「同じ値・フットプリント・型番」で分けるので、同じ型番が複数行に分かれることがある（ライブラリによって値の書き方が違うため）。
- 部品座標は mm 単位、表裏両面、DNP を除外。実装機用には `_smd.csv`（表面実装部品のみ）を渡す。
- Legacy / HRTIM の違いは LM5113 入力まわりの 12 点と、スイッチノード検出経路の 4 点（R343 / R344 / C338 / C339、HRTIM のみ実装）。**両方を同時に実装しないこと。**

## 基板の仕様と PCBWay の公開仕様の対比

PCBWay のウェブサイトに載っている数値（2026-11-14 に取得。ページに日付はなく、標準表と Advanced 表で食い違う項目もあるので、見積もり時に確認すること）と、この基板の設計値。

| 項目 | この基板 | PCBWay の公開値 | 判定 |
|---|---|---|---|
| 層数・外形 | 4 層、70 × 80 mm、四隅 R5 | 1〜14 層、最小 3 × 3 mm | 問題なし |
| 最小線幅 / 間隔 | 0.2 / 0.2 mm | 0.1 / 0.1 mm（4 mil） | 余裕あり |
| ビア | パッド 0.6 mm、穴 0.3 mm（全数） | 最小穴 0.15 mm、0.2 mm 未満は追加料金 | 問題なし |
| 部品穴の最小 | 0.70 mm（J3、ランド 1.05 mm、1.27 mm ピッチ 14 穴。ランド間 0.22 mm） | — | 問題なし |
| アニュラリング | 0.15 mm | 最小 0.15 mm（6 mil） | **下限ちょうど** |
| 銅箔と基板端 | 0.3 mm 以上 | 0.25 mm（ルーター外形、標準） | 問題なし |
| レジストのダム | 0.5 mm ピッチ部品で 0.1 mm | 緑で 4 mil（0.10 mm）、他色は 4.5 mil 以上 | **下限。緑以外だとピン間のレジストが無くなる可能性** |
| 最小チップ部品 | 0402 | 01005 / 0201 / 0402 まで可 | 問題なし |
| 実装形態 | 両面 SMT ＋ スルーホール | SMT / THT / 混在、片面・両面に対応 | 問題なし |

出典: `pcbway.com/capabilities.html`、`assembly-capabilities.html`、`assembly-file-requirements.html`、`assembly-special-remind.html`。

## 発注時に確認すること

- **捨て基板（レール）が必要**。PCBWay は「基板端と銅箔の距離が 3.5 mm 未満ならレールが必要」としており、この基板はコネクタやスイッチのパッドが端から 2 mm 以内にある（最も近いものは約 0.5 mm）。基板データにレールは入れていないので、実装業者側で付けてもらうよう依頼する。**フィデューシャルは基板内に表裏 3 個ずつある**（直径 1 mm、レジスト開口 2 mm。(163.0, 133.2)、(209.5, 127.4)、(160.5, 202.0)。左上の角を原点にすると (13.0, 8.2)、(59.5, 2.4)、(10.5, 77.0)）。
- **面付けの要否**。同じページに「50 × 100 mm より小さい基板は面付けが必要」とある一方、別ページでは最小 10 × 10 mm となっている。70 × 80 mm がどちらに当たるかは問い合わせること。
- レジストは緑を選ぶか、0.5 mm ピッチ部品（MCU、LM5113 など）のピン間レジストが無くなることを許容する。
- 0201 / 0402 部品について「最低 100 個、かつ必要数より 50 個多く」という記載がある（部品を支給する場合の条件と思われる。要確認）。
- 両面実装。裏面にも 0402 を中心に部品がある。
- EPC2007C（バンプ実装の GaN FET）と LM5113-Q1（WSON）はリフロー必須。
- スルーホール部品: ピンヘッダ J1 / J2、デバッグコネクタ J3、エンコーダ SW1、スライドスイッチ SW2、既存の電源コネクタ類。**J4（1×4）は実装しない**（フットプリントだけ残してある）。
- 改訂 4 で足した IC: TLV3601DBVR（SOT-23-5）× 2（U308 / U309、表面の上辺）。本体の下にビアが 3 個ずつあるが、レジストで覆われている。
- **J3 は Samtec FTSH-107-01-L-D-K**（2×7、1.27 mm ピッチ、スルーホール、キー付きシュラウド）。**シュラウドのキー溝（切り欠き）が基板端（西）側**になる向きで実装する。1 番ピンは北西の角（四角いランド）。表面実装品（-DV-K）とは互換が無い。
- 取付穴は M3 が 4 個（基板端から 5 mm、間隔 60 × 70 mm、GND のめっき穴）。四隅は取付穴を中心とする R5。
- スライドスイッチ SW2 の下に、シルクの帯（幅 0.8 mm、四辺）がある。金属カバーの下の絶縁を兼ねているので、シルクを省略・間引きしないこと（`docs/stm32-tx/layout_notes.md` §7.3）。
- 実装指示（BOM の Notes 列）が付いている部品: J3（キー溝の向き）、J5（シェルの脚 4 か所のはんだ付け）、SW1（枠ラグ 2 か所のはんだ付け）、D201（同等品可）、U3（ST 純正）、ジャンパ（挿す位置）。
- **ジャンパ 2 個が要る**: CN207 の 1–2 番（7 V コンバータを DC ジャックから給電）と CN203 の 1–2 番（VPP を基板内のコンバータから供給）。1 番は四角いランド。挿さないと DC ジャックから給電されない。実装業者に挿してもらうか、届いてから挿す。
- **支払いの前に MCU（STM32G474RET6）の在庫と納期を確認する**。2026-11-14 時点で Digi-Key は在庫 0・納期 52 週だった。入手性の一覧は `docs/stm32-tx/preorder_review.md` §2.5。
- 包装の記号（リール / カットテープ / トレイ）は問わないと伝える。
